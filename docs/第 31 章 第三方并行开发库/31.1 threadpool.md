# 31.1 threadpool

[`threadpool`](https://docs.rs/threadpool/latest/threadpool/) 将多个任务交给固定数量的工作线程，不为每个任务创建新线程。`execute` 提交任务但不返回单个任务的 `JoinHandle`；可用管道取回结果，用 `join` 等待池中的任务完成。

在 Edition 2024 的 Cargo 项目中安装依赖，再把下面的代码放到 `src/main.rs`，用 `cargo run` 运行。示例依赖外部 crate，单文件 `rustc` 审计跳过此围栏。

```sh
cargo add threadpool@1.8
```

```rust,ignore,no_run
use std::sync::mpsc::channel;
use threadpool::ThreadPool;

fn main() {
    let pool = ThreadPool::new(2);
    let (tx, rx) = channel();

    for n in 1..=4 {
        let tx = tx.clone();
        pool.execute(move || tx.send(n * n).unwrap());
    }

    drop(tx);
    pool.join();
    assert_eq!(rx.iter().sum::<i32>(), 30);
}
```

任务必须满足 `Send + 'static`，因为执行它的工作线程可能比提交任务的函数活得更久。示例用无界管道返回结果，所以等待池结束前无需接收消息。
