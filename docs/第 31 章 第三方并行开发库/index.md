# 第 31 章 第三方并行开发库

标准库提供线程和同步原语，第三方库则把常见模式封装成更高层的 API。先按实际需求选工具，不必为并行一开始就引入依赖。

| 需求 | 选择 |
| --- | --- |
| 让固定数量的工作线程重复处理独立任务 | `threadpool` |
| 让任务临时借用局部数据 | 优先考虑 `std::thread::scope`；已有项目也可能使用 `scoped_threadpool` |
| 想要不同语义的互斥锁和条件变量 | `parking_lot` |
| 多消费者从同一个队列竞争接收 | `crossbeam-channel` |
| 并行处理集合或拆分 CPU 密集型任务 | Rayon |
