# 31.4 crossbeam

[Crossbeam](https://github.com/crossbeam-rs/crossbeam) 提供并发工具。这里用其中的 [`crossbeam-channel`](https://docs.rs/crossbeam-channel/latest/crossbeam_channel/)：与标准库的 MPSC 不同，它的发送端和接收端都可以克隆。多个接收者从同一队列取消息，每条消息只交给其中一个，不是广播。

在 Edition 2024 的 Cargo 项目中安装依赖，再把下面的代码放到 `src/main.rs`，用 `cargo run` 运行。示例依赖外部 crate，单文件 `rustc` 审计跳过此围栏。

```sh
cargo add crossbeam-channel@0.5
```

```rust,ignore,no_run
use crossbeam_channel::bounded;
use std::thread;

fn main() {
    let (tx, rx) = bounded(2);
    let handles = [rx.clone(), rx].map(|rx| {
        thread::spawn(move || rx.recv().unwrap())
    });

    tx.send("甲").unwrap();
    tx.send("乙").unwrap();

    let mut received = handles.map(|handle| handle.join().unwrap());
    received.sort_unstable();
    assert_eq!(received, ["乙", "甲"]);
}
```

不能预测哪一个消费者拿到哪条消息。若要等待**多条管道**中任意一个操作就绪，可使用当前 API 的 [`select!`](https://docs.rs/crossbeam-channel/latest/crossbeam_channel/macro.select.html)；单一队列的分工不需要它。
