# 31.4 crossbeam

[Crossbeam](https://github.com/crossbeam-rs/crossbeam) 提供并发工具。这里用其中的 [`crossbeam-channel`](https://docs.rs/crossbeam-channel/latest/crossbeam_channel/)：与标准库的 MPSC 不同，它的发送端和接收端都可以克隆。多个接收者从同一队列取消息，每条消息只交给其中一个，不是广播。

在 Edition 2024 的 Cargo 项目中安装依赖，再把下面的代码放到 `src/main.rs`，用 `cargo run` 运行。示例依赖外部 crate，单文件 `rustc` 审计跳过此围栏。

```sh
cargo add crossbeam-channel@0.5
```

```rust,cargo=crossbeam-channel,no_run
use crossbeam_channel::bounded;
use std::thread;

fn main() {
    let (tx, rx) = bounded(2);
    let handles = [rx.clone(), rx].map(|rx| {
        thread::spawn(move || rx.recv().unwrap())
    });

    tx.send("甲").unwrap();
    tx.send("乙").unwrap();

    let mut received = handles.map(|handle| handle.join().unwrap());
    received.sort_unstable();
    assert_eq!(received, ["乙", "甲"]);
}
```

不能预测哪一个消费者拿到哪条消息。每条管道仍是单向的；不过同一线程可以同时持有发送和接收端。若要从多个可能的收发操作中择一个执行，可以使用 [`select!`](https://docs.rs/crossbeam-channel/latest/crossbeam_channel/macro.select.html)。

## 在发送与接收之间选择

下面用配对例子演示：每个人尝试发送自己的名字，或接收其他人的名字，选择一个当前可以进行的操作。仍使用上面的 `crossbeam-channel` 依赖；用标准库的 `scope` 创建线程，再用 `select!` 选择操作：

```rust,cargo=crossbeam-channel,no_run
use crossbeam_channel::{bounded, select};
use std::thread;

fn main() {
    let people = ["Anna", "Bob", "Cody", "Dave", "Eva"];
    let (tx, rx) = bounded(1);

    thread::scope(|scope| {
        for name in people {
            let (tx, rx) = (&tx, &rx);
            scope.spawn(move || {
                select! {
                    recv(rx) -> peer => println!("{name} received {}", peer.unwrap()),
                    send(tx, name) -> sent => sent.unwrap(),
                }
            });
        }
    });

    if let Ok(name) = rx.try_recv() {
        println!("No one received {name}'s message.");
    }
}
```

容量为 1，发送者可以先留下一条暂未被匹配的消息。每个人只完成一次收或发；因为人数是奇数，最终有一条消息留在队列中。谁与谁配对、谁落单都是由执行顺序决定的。
