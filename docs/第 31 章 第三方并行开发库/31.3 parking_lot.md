# 31.3 `parking_lot`

[`parking_lot`](https://docs.rs/parking_lot/latest/parking_lot/) 提供与标准库相似的锁与条件变量。下面用作用域线程共享一把锁：

在 Edition 2024 的 Cargo 项目中安装依赖，再把下面的代码放到 `src/main.rs`，用 `cargo run` 运行。示例依赖外部 crate，单文件 `rustc` 审计跳过此围栏。

```sh
cargo add parking_lot@0.12
```

```rust,cargo=parking_lot,no_run
use parking_lot::Mutex;
use std::thread;

fn main() {
    let counter = Mutex::new(0);
    thread::scope(|scope| {
        for _ in 0..2 {
            scope.spawn(|| {
                *counter.lock() += 1;
            });
        }
    });

    assert_eq!(*counter.lock(), 2);
}
```

| 特性 | `std::sync::Mutex` | `parking_lot::Mutex` |
| --- | --- | --- |
| `lock()` 返回 | `LockResult<MutexGuard>` | 直接返回守卫 |
| 持锁时 panic | 通常标记锁中毒 | 释放锁但不标记中毒 |

不标记中毒不等于数据一定保持一致：如果 panic 可能打断多步更新，使用者仍需维护业务约束。性能差异取决于平台和负载，应按实际场景测量。
