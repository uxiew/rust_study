# 18.1 什么是 panic

`panic` 表示当前路径无法按正常约定继续执行，例如在 `None` 上调用 `unwrap`。以下程序能编译，运行时会故意 panic。

```rust
fn main() {
    let answer: Option<i32> = None;
    answer.unwrap();
}
```

典型诊断如下；设置 `RUST_BACKTRACE=1` 可查看调用栈：

```text
thread 'main' panicked at main.rs:3:12:
called `Option::unwrap()` on a `None` value
```

如果没有值是正常情况，就显式处理它。例如需要一个默认值时使用 `unwrap_or`；需要返回错误时可以用 `ok_or` 把 `Option` 转为 `Result`。

```rust
fn main() {
    let answer: Option<i32> = None;
    assert_eq!(answer.unwrap_or(42), 42);
    assert_eq!(answer.ok_or("没有答案"), Err("没有答案"));
}
```
