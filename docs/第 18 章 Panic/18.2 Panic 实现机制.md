# 18.2 Panic 实现机制

| 策略 | panic 之后 | `catch_unwind` |
| --- | --- | --- |
| `unwind` | 展开当前线程的栈，通常会析构沿途的局部值。 | 可以拦住展开中的 panic。 |
| `abort` | 终止整个进程，不展开栈。 | 不能拦住。 |

默认策略取决于编译目标，常用桌面目标通常用 `unwind`。可以保存下面的代码为 `test.rs`，再分别编译：

```sh
rustc --edition 2024 -C panic=unwind test.rs -o panic-unwind
rustc --edition 2024 -C panic=abort test.rs -o panic-abort
```

```rust
fn main() {
    let result = std::panic::catch_unwind(|| panic!("演示 panic"));
    assert!(result.is_err());
    println!("展开已被拦截");
}
```

默认 panic 钩子会在尝试捕获前打印信息；看到消息不代表没有捕获。文件不存在等预期错误仍应使用 `Result`，不要改成 panic 再捕获。

在 FFI 中，ABI 决定是否允许展开跨过边界。Rust panic 到达不允许展开的 ABI（如 `extern "C"`）会中止进程；外部异常经不允许展开的 ABI 进入 Rust 是未定义行为。不要把 `catch_unwind` 当作通用的外部异常处理器。
