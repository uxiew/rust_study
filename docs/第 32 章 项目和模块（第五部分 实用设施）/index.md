# 第 32 章 项目和模块（第五部分 实用设施）

Rust 用包、crate 和模块三个层次组织项目：

| 层次 | 作用 |
| --- | --- |
| Cargo 包（package） | 由 `Cargo.toml` 描述，管理依赖和编译目标 |
| crate | 独立编译单元，例如库或二进制；一个包可以有多个 crate |
| 模块（module） | crate 内部的命名空间，组织代码和限制可见性 |

crate 之间不能循环依赖；同一个 crate 内，两个模块可以互相引用对方可见的项。一个模块也可以分布在多个文件中，因此不能把单个 `.rs` 文件等同于独立的编译单元。
