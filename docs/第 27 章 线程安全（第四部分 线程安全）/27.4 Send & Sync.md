# 27.4 Send & Sync

| Trait | 对 `T` 的要求 |
| --- | --- |
| `Send` | 可以把 `T` 的所有权转移到另一个线程 |
| `Sync` | 可以让不同线程共享使用 `&T`，即 `&T: Send` |

[`std::thread::spawn`](https://doc.rust-lang.org/std/thread/fn.spawn.html) 的签名如下（只展示接口）：

```text
pub fn spawn<F, T>(f: F) -> JoinHandle<T>
where
    F: FnOnce() -> T + Send + 'static,
    T: Send + 'static,
```

`F: Send` 是因为闭包要被送入子线程；`T: Send` 是因为子线程的返回值可能通过 `join` 送回调用者。`'static` 不意味着值必须活到进程退出，而是其中不能含有短期借用。

`spawn` 没有直接要求 `Sync`。但闭包捕获 `&T` 时，需要把这份共享引用送到子线程，这时 `T: Sync` 就派上用场了。
