# 7.3 if-let 和 while-let

## 从 `match` 到 `if let`

假设有个变量 `opt_val`，它的类型是 `Option<i32>`。我们只关心它是 `Some` 的情况：取出里面的值做些事情，如果是 `None` 就不做任何处理。用 `match` 来写：

```rust
fn do_something_with(x: i32) { println!("{x}"); }
let opt_val = Some(5);
match opt_val {
    Some(x) => do_something_with(x),
    None => {}
}
```

即使不需要处理 `None`，为了穷尽匹配也要写一个分支。我们也可以把检查和取值分开：

```rust
fn do_something_with(x: i32) { println!("{x}"); }
let opt_val = Some(5);
if opt_val.is_some() {
    let x = opt_val.unwrap();
    do_something_with(x);
}
```

代码少了一层缩进，但读者要同时跟踪检查和取值，确认 `unwrap()` 不会遇到 `None`。实际机器码是否包含额外判断取决于优化，不能仅凭这两行判断速度。用 `if let` 则能在匹配成功时直接取出值：

```rust
fn do_something_with(x: i32) { println!("{x}"); }
let opt_val = Some(5);
if let Some(x) = opt_val {
    do_something_with(x);
}
```

它是一个语法糖：把关心的模式放在等号左边，待匹配的表达式放在右边。匹配成功时，变量 `x` 只在分支内可用；不成功时，若没有 `else`，就跳过分支。与之类似，`while let` 在每轮开头重新匹配，直到匹配失败才退出。


| 写法 | 何时使用 |
| --- | --- |
| `match` | 需要覆盖所有可能分支 |
| `if let` | 只关心一类匹配；可用 `else` 处理其他情况 |
| `while let` | 只要还能匹配，就继续循环 |
| `let … else` | 希望绑定在后续可用，匹配失败就提前退出 |
| let chain | 在同一个条件中依次匹配和判断 |

## 只处理感兴趣的模式

`if let` 和 `while let` 都支持 `|`（或模式）。每个备选模式必须以相同的方式绑定相同名字。

先看不需要绑定的情况：当 `x` 是 `E::C` 或 `E::D` 时返回 1，否则返回 2。这两种写法含义相同：

```rust
enum E { C, D, Other }

let x = E::D;
let r = if let E::C | E::D = x { 1 } else { 2 };
let same = match x {
    E::C | E::D => 1,
    _ => 2,
};
assert_eq!(r, same);
```

如果两个变体都含有同类型的值，可以绑定同一个名字。在下面的示例里，`text` 不管来自哪个模式，都是一个 `String`；后半段再用 `while let` 从栈中连续取值。


```rust
enum Message { Text(String), Alias(String), Quit }

fn main() {
    let event = Message::Alias(String::from("hello"));
    if let Message::Text(text) | Message::Alias(text) = event {
        assert_eq!(text, "hello");
    }

    let mut numbers = vec![1, 2, 3];
    let mut sum = 0;
    while let Some(number) = numbers.pop() {
        sum += number;
    }
    assert_eq!(sum, 6);
}
```

## 提前返回与组合条件

::: tip 新版变化
`let … else` 从 Rust 1.65 起稳定，其 `else` 必须用 `return`、`break` 等离开当前流程。let chains 从 Rust 1.88 起可用于 [Edition 2024](https://doc.rust-lang.org/edition-guide/rust-2024/let-chains.html)，用 `&&` 串联条件，前面绑的名字可以用在后面。
:::

```rust
fn positive(input: Option<&str>) -> Option<u32> {
    let Some(text) = input else { return None };

    if let Ok(number) = text.parse::<u32>() && number > 0 {
        Some(number)
    } else {
        None
    }
}

fn main() {
    assert_eq!(positive(Some("42")), Some(42));
    assert_eq!(positive(Some("0")), None);
    assert_eq!(positive(None), None);
}
```
