# 33.4 main 函数中使用问号运算符

默认的 `fn main()` 返回 `()`，无法用 `?` 传播 `Result` 的错误。下面这个完整反例会出现 E0277：`()` 不能接收提前返回的错误。

```rust,compile_fail,no_run
fn main() {
    let n = "42".parse::<i32>()?;
    println!("{n}");
}
```

改用 `Result` 作为返回类型即可：

```rust
use std::error::Error;

fn main() -> Result<(), Box<dyn Error>> {
    let input = std::env::args().nth(1).unwrap_or_default();
    let n = input.parse::<i32>()?;
    println!("{n}");
    Ok(())
}
```

用 `cargo run -- 42` 会输出 `42` 并成功退出；不传参数或传入非整数会报错并以非零状态退出。标准库对 `Result` 的默认处理会以 `Debug` 格式向标准错误输出错误值。

`main` 的返回类型必须实现稳定的 [`std::process::Termination`](https://doc.rust-lang.org/std/process/trait.Termination.html)。它的 `report(self) -> ExitCode` 把返回值转换为进程退出状态。常见返回类型有 `()`、`Result<(), E>`（`E: Debug`）和 `ExitCode`；如果要自己控制诊断文本或退出码，可以在 `main` 中处理错误，再返回 `ExitCode`。

之所以不要求 `main` 永远返回同一种类型，是因为 Rust 运行时先做程序的启动工作，再调用我们写的 `main`，最后调用返回值的 `report`。旧程序返回 `()`，仍可正常退出；新程序返回 `Result`，可以统一把失败传给运行时。具体启动函数属于实现细节，不需要在应用代码中调用。
