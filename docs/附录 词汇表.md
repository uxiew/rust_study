# 附录 词汇表

| 词汇  | 解释 |
| ----------- | ----------- |
| ABI                        | Application Binary Interface       |
| Alias                      | 别名                                        |
| Arc                        | 原子引用计数智能指针 |
| Associated Item            | 关联条目，包括关联类型、关联方法、关联常量等       |
| Atomic                     | 原子的  |
| Attribute                  | 属性，给项等语法结构添加元数据或指令；部分属性由属性宏实现 |
| Borrow Check               | 借用检查 |
| Box                        | 具有所有权的智能指针  |
| Cargo                      | Rust 的官方包管理工具  |
| Closure                    | 闭包  |
| Compile Unit               | 编译单元  |
| Constructor                | 构造器  |
| Copy                       | 标记类型支持隐式按位复制的 trait |
| Crate                      | Rust 的基本编译单元  |
| Crate Root                 | crate 根模块；Cargo 项目常从 `src/lib.rs`、`src/main.rs` 开始 |
| Data Race                  | 数据竞争  |
| Dereference                | 解引用 |
| Destructor                 | 析构函数  |
| Destructure                | 解构  |
| diverge function           | 发散函数，永远不会返回的函数  |
| DST                        | Dynamically Sized Type，无法仅从类型在编译时确定大小的类型 |
| Dyn Compatibility          | dyn 兼容性（旧称 Object Safety）；trait 能否用作 trait 对象的基础 trait |
| Edition                    | 语言版本，如 2018、2021、2024，由包的 `Cargo.toml` 指定；不同于编译器版本 |
| Extern Prelude             | 外部 crate 预导入；自 Edition 2018 起通常可直接用依赖 crate 名开头的路径 |
| Fat Pointer                | 胖指针，即带有元数据（例如长度或虚表信息）的指针 |
| Feature Gate               | 实验性编译器功能的开关，不同于 Cargo 包的 features |
| FFI                        | Foreign Function Interface  |
|  Fn/FnMut/FnOnce           | 闭包相关的系列 trait  |
|  Generic                   | 泛型            |
|  Higher Rank Lifetime      | 高阶生命周期        |
|  Higher Rank Trait Bounds  | 高阶 trait 约束  |
|  Higher Rank Type          | 高阶类型系统        |
|  ICE                       | Internal Compiler Error 编译器内部错误  |
|  inherited mutability      | 承袭可变性        |
|  Interior Mutability       | 内部可变性         |
|  intrinsics                | 编译器内置函数 |
|  Iterator                  | 迭代器              |
|  Lifetime                  | 生命周期             |
|  Lifetime Elision          |  生命周期省略  |
|  Lint                      | 可自定义扩展的编译阶段检查  |
|  LLVM                      |  Low Level Virtual Machine  |
|  Macro                     |  宏  |
|  Memory Safety             | 内存安全，例如避免越界访问、释放后使用和数据竞争；不是仅指没有段错误 |
|  MIR                       |  Middle-level IR      |
|  Module                    | 模块  |
|  Move                      |  移动  |
|  Mutability                | 可变性  |
|  NLL                       | Non-Lexical Lifetimes，非词法生命周期，根据控制流和实际使用分析借用 |
|  OIBIT                     | Opt-in built-in trait，新名字为 Auto trait  |
|  Orphan Rules              | 孤儿规则  |
|  Ownership                 |  所有权 |
|  Package                   | Cargo 包，由 `Cargo.toml` 描述，可包含多个编译目标 |
|  Panic                     | 程序遇到无法继续当前操作的情况；根据配置展开栈或终止进程 |
|  Pattern Match             |  模式匹配 |
|  Placement New             | 在用户指定的内存位置上构建新的对象  |
|  Playground                | [Rust Playground](https://play.rust-lang.org/)，可在线编辑、编译和运行 Rust |
|  POD                       | Plain Old Data   |
|  Prelude                   | 预导入：自动进入作用域的一组名称，可随 Edition 变化 |
|  Race Condition            |  竞态条件     |
|  RAII                      | Resource Acquisition Is Initialization，利用对象生命周期管理资源 |
|  Rc                        | Reference Counted 引用计数智能指针  |
|  Release Channel           | 发布渠道  |
|  RFC                       |  Request For Comments 语言设计提案，FCP 指 Final Comment Period |
|  Rustc                     |  Rust 官方编译器的可执行文件名字   |
|  RVO                       |  Return Value Optimization    |
|  Self/self                 | 小写 s 是特殊变量，大写 S 是特殊类型 |
| Shadowing                  | 遮蔽：内侧或后续绑定让原有名称在相应作用域不可见；具体规则因命名空间而异 |
|  SIMD                      |  Single Instruction Multiple Data 单指令多数据流
|  Sized                     | 特殊的 trait，代表编译阶段类型的大小是已知的
|  Slice                     | 数组切片
|  Specialization            | 泛型特化
|  Stack Unwind              | 栈展开
|  STL                       |  standard template library 是 C++ 的标准模板库
|  Send                      | 自动 trait，表示值可在线程间转移所有权 |
|  Sync                      | 自动 trait，表示类型的共享引用可在线程间传递 |
|  TLS                       |  Thread Local Storage 线程局部存储
|  Toml                      |  一种文本文件格式
|  Trait Object              | trait 对象，如 `dyn Trait`，是一种 DST；通过引用或智能指针访问，使用虚表动态分发 |
|  TWiR                      |  This Week in Rust， 一个很有信息量的网站
|  Type Inference            |  类型自动推导
|  UFCS                      |  Universal Function Call Syntax，通用函数调用语法，后来改为 Fully Qualified Syntax
|  Unit Type                 |  单元类型，即空 tuple，记为`()`
|  Unsized Type              |  不满足 Sized 约束的类型
|  VTable                    |  虚函数表
|  ZST                       |  零大小数据类型

模块路径中，`crate::` 从当前 crate 根开始，`self::` 从当前模块开始，`super::` 从父模块开始；`pub use` 可将已有项重导出。
