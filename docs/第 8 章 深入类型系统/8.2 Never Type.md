# 8.2 Never Type

`()` 有一个值 `()`；空枚举没有变体，因此没有值。`!` 是 Rust 内置的无值类型，适合描述**不会正常返回**的表达式，例如 `return`、`continue` 或 `panic!`。无值不等于占用负数位，也不等于所有零大小类型都无值。

::: tip 新版变化
[从 Rust 1.100.0 起，`!` 稳定用于一般类型位置](https://doc.rust-lang.org/1.100.0/releases.html#version-11000-2026-11-12)，包括关联类型和泛型实参；更早的 Stable 已允许把它用作函数返回类型。
:::

## 分支中不会产生的值

```rust
fn main() {
    let mut total = 0;
    for value in [2, -1, 4] {
        let x: i32 = if value >= 0 { value } else { continue };
        total += x;
    }
    assert_eq!(total, 6);
}
```

`continue` 分支会直接开始下一轮，不会给 `x` 赋值。因此该分支的 `!` 可以强制转换成另一个分支需要的 `i32`；这并不是在运行时把一个值转成整数。

## 表达不会发生的错误

```rust
use std::str::FromStr;

#[derive(PartialEq, Debug)]
struct Text(String);

impl FromStr for Text {
    type Err = !;

    fn from_str(s: &str) -> Result<Self, Self::Err> {
        Ok(Self(s.to_owned()))
    }
}

fn main() {
    let Ok(text) = "hello".parse::<Text>();
    assert_eq!(text, Text(String::from("hello")));
}
```

当错误类型为 `!` 时，不可能构造 `Err`，所以上例的 `let Ok(text)` 不会匹配失败。如果需要兼容更早的编译器，可用 [`std::convert::Infallible`](https://doc.rust-lang.org/std/convert/enum.Infallible.html) 表达无错误类型；必要时显式处理 `Err(e) => match e {}`。

## Edition 2024 的类型推断

分支里的 `!` 有明确的目标类型时仍会正常强制转换。如果没有足够约束，Edition 2024 的 [never type fallback](https://doc.rust-lang.org/edition-guide/rust-2024/never-type-fallback.html) 从 `()` 改为 `!`。如果旧代码实际依赖推断出 `()`，请显式写出类型，例如把 `f()?;` 改成 `let (): () = f()?;`。
