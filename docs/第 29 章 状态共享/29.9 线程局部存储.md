# 29.9 线程局部存储

线程局部变量看似只有一个名字，实际上每个线程都有自己的值。稳定版用 `thread_local!` 声明，再通过 `with` 访问当前线程的副本。因为不共享同一个值，内部可以用 `Cell` 或 `RefCell`。

```rust
use std::{cell::Cell, thread};

thread_local! {
    static VALUE: Cell<u32> = const { Cell::new(1) };
}

fn main() {
    VALUE.with(|value| value.set(2));

    thread::spawn(|| {
        VALUE.with(|value| {
            assert_eq!(value.get(), 1);
            value.set(3);
        });
    }).join().unwrap();

    assert_eq!(VALUE.with(Cell::get), 2);
}
```

子线程初次访问得到 1，把自己的值改为 3 后，主线程的值仍是 2。初始化器支持时，可以像示例那样使用 `const { ... }`；它可让实现省去某些惰性初始化开销。

直接使用属性 `#[thread_local]` 仍需 Nightly 和 [`thread_local` 特性](https://doc.rust-lang.org/unstable-book/language-features/thread-local.html)，日常代码优先使用稳定的宏。
