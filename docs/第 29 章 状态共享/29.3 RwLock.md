# 29.3 RwLock

`RwLock<T>` 将共享读和独占写分成两个方法。像 `Mutex` 一样，守卫析构时会释放锁。

| 操作 | 同时允许的访问 |
| --- | --- |
| `read()` | 多个读者，不能有写者 |
| `write()` | 仅一个写者，不能有读者 |

```rust
use std::{sync::RwLock, thread};

fn main() {
    let values = RwLock::new(vec![1]);
    thread::scope(|scope| {
        scope.spawn(|| assert_eq!(values.read().unwrap()[0], 1));
        scope.spawn(|| assert_eq!(values.read().unwrap()[0], 1));
    });
    values.write().unwrap().push(2);
    assert_eq!(*values.read().unwrap(), [1, 2]);
}
```

写者持锁时 panic 可能导致锁中毒，读者持锁时 panic 不会。标准库不保证读者和写者的优先级；是否比 `Mutex` 更快，取决于读写比例和竞争情况。
