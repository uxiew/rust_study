# 29.8 全局变量

读写 `static mut` 需要 `unsafe`。下面是完整反例：

```rust,compile_fail,no_run
static mut COUNT: i32 = 0;

fn main() {
    COUNT = 1;
}
```

预期报错 **E0133**：修改可变静态项需要 `unsafe`。加上 `unsafe` 并不会自动处理同步或别名约束。

::: tip 新版变化
Edition 2024 默认拒绝创建指向 `static mut` 的引用（包括某些隐式借用）。优先使用原子类型、`Mutex<T>` 或 `LazyLock<T>`，将同步约束放进类型里。
:::

普通共享 `static` 的类型必须是 `Sync`，即使代码还没创建任何线程也是如此：

```rust,compile_fail,no_run
use std::cell::Cell;

static COUNT: Cell<i32> = Cell::new(0);

fn main() {
    COUNT.set(1);
}
```

预期报错 **E0277**：`Cell<i32>` 有内部可变性，却没有跨线程同步，所以不是 `Sync`。对于全局计数器，可改用原子整数：

```rust
use std::{sync::atomic::{AtomicUsize, Ordering}, thread};

static COUNT: AtomicUsize = AtomicUsize::new(0);

fn main() {
    let worker = thread::spawn(|| COUNT.fetch_add(1, Ordering::Relaxed));
    COUNT.fetch_add(1, Ordering::Relaxed);
    worker.join().unwrap();
    assert_eq!(COUNT.load(Ordering::Relaxed), 2);
}
```

| 全局状态 | 推荐类型 |
| --- | --- |
| 独立计数或标记 | 原子整数或 `AtomicBool` |
| 多字段共享可变状态 | `Mutex<T>` 或 `RwLock<T>` |
| 首次访问时初始化 | `LazyLock<T>`；若由调用者提供初始值，可用 `OnceLock<T>` |
