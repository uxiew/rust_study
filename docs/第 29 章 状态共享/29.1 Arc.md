# 29.1 Arc

`Arc<T>` 是原子引用计数智能指针（Atomic Reference Counted）。克隆时只增加引用计数，不复制 `T`；最后一个强引用被丢弃时，内部值随之析构。

```rust
use std::{sync::Arc, thread};

fn main() {
    let numbers = Arc::new(vec![10, 20, 30]);
    let child_numbers = Arc::clone(&numbers);
    let worker = thread::spawn(move || child_numbers.iter().sum::<i32>());

    assert_eq!(worker.join().unwrap(), 60);
    assert_eq!(numbers.len(), 3);
}
```

| 指针类型（默认分配器） | 跨线程条件 |
| --- | --- |
| `Rc<T>` | 既不是 `Send` 也不是 `Sync`；引用计数不是原子的 |
| `Arc<T>` | 当 `T: Send + Sync` 时同时实现 `Send` 和 `Sync` |

这里闭包拥有 `Arc<Vec<i32>>`，而 `Vec<i32>` 同时是 `Send` 和 `Sync`，因此能把闭包交给 `spawn`。如果换成 `Arc<Cell<i32>>`，即使引用计数是原子的，内部的 `Cell` 仍不是 `Sync`。要跨线程共享并修改，可用下一节的 `Arc<Mutex<T>>`。
