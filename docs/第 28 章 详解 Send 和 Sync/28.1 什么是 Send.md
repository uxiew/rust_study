# 28.1 什么是 Send

`T: Send` 表示可以安全地把一个 `T` 的所有权交给另一个线程。比如 `String` 是 `Send`，`Vec<T>` 在 `T: Send` 时也是 `Send`。没有借用不代表一定是 `Send`：`Rc<T>` 即使持有一个整数，克隆出来的指针仍可能在原线程操作同一个非原子引用计数。

`Mutex<T>` 不会把 `!Send` 的类型变成 `Send`；它要求 `T: Send`，例如调用 `into_inner` 可以在当前线程取出内部值。`Arc<T>` 用原子操作保护自己的引用计数，但仍要求内部的 `T: Send + Sync`（使用默认分配器时），详见第 29 章。

```rust,compile_fail,no_run
use std::{rc::Rc, thread};

fn main() {
    let number = Rc::new(42);
    thread::spawn(move || println!("{}", *number));
}
```

预期报错 **E0277**：闭包持有的 `Rc<i32>` 没有实现 `Send`。如果只需要发送整数，可以在线程外先取出整数，只把整数交给闭包。
