# 28.2 什么是 Sync

`T: Sync` 当且仅当 `&T: Send`：可以把共享引用发送到别的线程。关键不在于有没有内部可变性，而在于通过共享引用修改数据时，是否使用了正确的同步机制。

| 类型 | 是否可通过共享引用跨线程使用 |
| --- | --- |
| `i32` | 是；`&i32` 只允许读取 |
| `Cell<T>`、`RefCell<T>` | 否；通过共享引用修改时没有跨线程同步 |
| `Mutex<T>` | 当 `T: Send` 时可以；锁同时只让一个线程访问内部值 |
| `RwLock<T>` | 当 `T: Send + Sync` 时可以；多个读者可以同时持有内部值的共享引用 |

因此，`Cell<i32>` 可以整个搬到另一个线程（`Send`），但不能让两个线程各拿一份 `&Cell<i32>`（不是 `Sync`）。`Mutex<Cell<i32>>` 则可以通过共享引用传给不同线程，因为每次访问都必须持有独占的锁守卫。
