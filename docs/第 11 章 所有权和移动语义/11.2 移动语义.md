# 11.2 转移语义

对 `String` 这类非 `Copy` 的值，赋值、传参和返回都可能转移所有权（move）。新绑定接手同一个值，原位置在重新初始化前不能再读，也不会再次析构这个值。

```rust
fn create() -> String {
    String::from("hello")
}

fn consume(s: String) {
    println!("{s}");
}

fn main() {
    let s = create();
    consume(s);
}
```

```mermaid
flowchart LR
    A["create 创建 String"] -->|"返回：移动"| B["main 中的 s"]
    B -->|"传参：移动"| C["consume 中的 s"]
    C -->|"函数返回"| D["析构 String，释放缓冲区"]
```

移动 `String` 不会克隆堆上的字符。如果要保留原值，可传 `&str` 借用它，或者用 `s.clone()` 创建独立的字符串。

移动是**语义保证**，不是一条必须执行的 `memcpy` 指令。编译器可以把返回值直接写进调用方提供的位置；程序不能依赖它究竟移动了多少字节。
