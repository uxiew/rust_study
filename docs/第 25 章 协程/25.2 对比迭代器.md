# 25.2 对比迭代器

在 Rust 中，迭代器指的是实现了 `std::iter::Iterator` trait 的类型：

```rust
pub trait Iterator {
    type Item;

    fn next(&mut self) -> Option<Self::Item>;
    // 省略有默认实现的方法
}
```

这个 trait 最主要的一个方法就是 `next` 方法。每次调用，它都会返回下一个元素，没有下一个元素时返回 `None`；只有 `FusedIterator` 等才保证后续调用始终是 `None`。使用方法如下：

```rust
let mut it = 1..3;
while let Some(item) = it.next() {
    println!("{item}");
}
```

`next` 方法接受的参数是`&mut Self` 类型。因为它每次调用的时候，都要修改内部的状态，只有这样，下一次调用的时候才会返回不同的内容。如果内部是指针，需要把指针指向容器的下一个元素；如果内部是索引，就需要更新索引的值。

迭代器也可以不指向任何容器，只要它满足 `Iterator` trait 这个接口即可。比如 `std::ops::Range` 这个类型，它代表一个前闭后开的区间，也可以进行迭代，只是每次调用 `next` 后它代表的区间就变了。

任何一个生成器，总能找到某种办法改写为功能相同的迭代器。还是以前面的 Fibonacci 数列为例，如果改成迭代器的样子，该像下面这样写：

```rust
// 方案二
struct Fibonacci {
    curr: Option<u64>,
    next: Option<u64>,
}

impl Iterator for Fibonacci {
    type Item = u64;

    fn next(&mut self) -> Option<u64> {
        let value = self.curr?;
        self.curr = self.next;
        self.next = self.next.and_then(|n| value.checked_add(n));
        Some(value)
    }
}

fn fibonacci() -> Fibonacci {
    Fibonacci { curr: Some(1), next: Some(1) }
}

fn main() {
    assert_eq!(fibonacci().take(6).collect::<Vec<_>>(), [1, 1, 2, 3, 5, 8]);
}
```

这段代码同样也能实现打印 Fibonacci 数列的功能。请读者逐行逐字读一下 `next` 方法的逻辑，看清楚它是如何记录状态的，理解为什么每次调用 `next` 方法都会返回不同的值。这个示例在后文还会继续使用。

迭代器是典型的“拉”模式：消费方调用 `next` 才取到下一项。[25.1](./25.1%20基础简介.md) 的 `gen` 块也提供 `Iterator` 接口，而 [25.4](./25.4%20协程.md) 的 `Coroutine` 使用 `resume`，除中间产出外还可传入恢复参数和返回完成值。
