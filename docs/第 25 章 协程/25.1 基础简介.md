# 25.1 简介

协程能够暂停执行，并在之后从暂停的位置继续。普通函数调用要等到函数返回；协程则可以在完成前多次把控制权交回调用方，并保存恢复所需的局部状态。

## 25.1.1 `yield` 关键字

在实验性的 Rust 协程中，`yield value` 暂停执行，并把 `value` 交给调用方。调用方用 `resume` 恢复协程；最后由 `return` 或末尾表达式给出完成值。完整例子见 [25.4 协程](./25.4%20协程.md)。

## 25.1.2 生成器（Generator）

生成器只关心逐个产出元素，可以通过 `Iterator` 消费。不要把 `gen` 块和 `#[coroutine]` 的调用接口混用：前者通过 `next` 拉取元素，后者通过 `resume` 恢复。

::: tip 新版变化
Edition 2024 保留了 `gen` 关键字，但 Rust 1.100 稳定版仍不能使用 `gen { ... }`。下面需 Nightly 的 [`gen_blocks`](https://doc.rust-lang.org/unstable-book/language-features/gen-blocks.html)。Cargo 项目用 `edition = "2024"` 和 `cargo +nightly run`，不需要旧的 edition 特性开关。
:::

```rust:{channel:"nightly",edition:"2024"}
#![feature(gen_blocks)]

fn main() {
    let values = gen {
        yield 1;
        yield 2;
    };
    assert_eq!(values.collect::<Vec<_>>(), [1, 2]);
}
```

## 25.1.3 生成 Fibonacci 数列

在稳定版可以用 `std::iter::from_fn`。下面的闭包保存相邻两项，调用一次就返回一项。`checked_add` 处理溢出，仍返回最后一个能用 `u64` 表示的项。

```rust
fn fibonacci() -> impl Iterator<Item = u64> {
    let (mut current, mut next) = (Some(1_u64), Some(1_u64));
    std::iter::from_fn(move || {
        let value = current?;
        current = next;
        next = next.and_then(|n| value.checked_add(n));
        Some(value)
    })
}

fn main() {
    assert_eq!(fibonacci().take(6).collect::<Vec<_>>(), [1, 1, 2, 3, 5, 8]);
}
```

`yield` 会显式产出值；稳定的 `.await` 则是在等待的 Future 尚未就绪时暂停当前异步逻辑，见 [25.5 异步](./25.5%20异步.md)。
