# 30.2 同步管道

`mpsc::sync_channel(n)` 使用有界缓冲。缓冲区满时，`send` 会阻塞，直到接收者腾出空间。这能让较慢的接收者限制生产速度，称为**背压**。

```rust
use std::sync::mpsc::{TrySendError, sync_channel};

fn main() {
    let (tx, rx) = sync_channel(1);
    tx.send(1).unwrap();
    assert_eq!(tx.try_send(2), Err(TrySendError::Full(2)));

    assert_eq!(rx.recv().unwrap(), 1);
    tx.send(2).unwrap();
    assert_eq!(rx.recv().unwrap(), 2);
}
```

示例使用 `try_send` 无阻塞地观察缓冲区已满；如果在同一线程中改成第二次调用 `send`，就等不到后面的 `recv` 了。

当容量为 0 时没有队列，`send` 成功意味着消息已交给接收者，而不意味着接收者已处理完。标准库的每条管道都是单向的，需要双向通信时可建立两条方向相反的管道。
