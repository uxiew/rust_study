# 22.2 move 关键字

返回闭包时，不能让它借用即将被销毁的局部变量。下面预期报 E0373：闭包借用了 `x`，却要离开 `make_adder`。

```rust,compile_fail,no_run
fn make_adder(x: i32) -> impl Fn(i32) -> i32 {
    |y| x + y
}
```

用 `move` 按值捕获。这里 `i32` 实现了 `Copy`，闭包存入的是 `x` 的副本；如果捕获的是 `String`，则会移入其所有权。

```rust
fn make_adder(x: i32) -> impl Fn(i32) -> i32 {
    move |y| x + y
}

fn main() {
    let add_three = make_adder(3);
    assert_eq!(add_three(1), 4);
    assert_eq!(add_three(10), 13);
}
```

`move` 不决定闭包只能调用一次。上例只读取捕获的值，所以仍实现 `Fn`。若捕获的值本身是引用，`move` 只移动或复制引用，不延长被引用对象的生命周期。
