# 22.3 Fn/FnMut/FnOnce

闭包的捕获方式决定环境中存什么；闭包体如何使用这些值，决定它实现哪些调用 trait。小写 `fn` 是函数关键字，`Fn` 则是标准库 trait。

| trait | 调用时如何取得闭包环境 | 典型用法 |
| --- | --- | --- |
| `FnOnce` | 按值 `self` | 消费捕获值，例如移出一个 `String` |
| `FnMut` | 独占借用 `&mut self` | 修改捕获值，但不移出它 |
| `Fn` | 共享借用 `&self` | 只读捕获值，或通过内部可变性更新状态 |

每个闭包都实现 `FnOnce`；实现 `Fn` 的闭包也实现 `FnMut`。接受回调时，应选够用的最宽松约束：如果只调用一次，通常使用 `FnOnce`。稳定版通过 `f(...)` 调用，不直接调用实验性的 `call_once` 等方法。

```rust
fn twice(mut f: impl FnMut()) {
    f();
    f();
}

fn main() {
    let mut count = 0;
    twice(|| count += 1);
    assert_eq!(count, 2);

    let text = String::from("Rust");
    let len = move || text.len();
    assert_eq!(len(), len()); // 按值捕获，但没有移出 String
}
```

反例预期 E0382：第一次调用把闭包按值消耗，不能再次调用。

```rust,compile_fail,no_run
fn main() {
    let text = String::from("Rust");
    let consume = || drop(text);
    consume();
    consume();
}
```
