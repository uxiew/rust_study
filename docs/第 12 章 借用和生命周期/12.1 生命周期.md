# 12.1 生命周期

本书有时用“存活”描述值从初始化到释放，用“作用域”描述变量名在哪些位置可见。在 Rust 的类型里，`'a` 这样的生命周期参数描述的是引用必须有效的范围，不等于这两个概念。先看局部值的例子：

```rust
fn main() {
    let v = vec![1,2,3,4,5];        // --> v 的生命周期开始
    {
        let center = v[2];          // --> center 的生命周期开始
        println!("{}", center);
    }                               // <-- center 的生命周期结束
    println!("{:?}", v);
}                                   // <-- v 的生命周期结束
```

然而，如果一个变量永远只能有唯一一个入口可以访问的话，那就太难使用了。因此，所有权还可以借用。
