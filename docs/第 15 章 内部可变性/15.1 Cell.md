# 15.1 Cell

[`Cell<T>`](https://doc.rust-lang.org/std/cell/struct.Cell.html) 允许通过共享引用替换整个值，但不从 `&Cell<T>` 借出内部的 `&T` 或 `&mut T`。这样，一个共享使用者更新值时，其他使用者不会持有指向旧值的普通引用。

```rust
fn main() {
    use std::cell::Cell;

    let count = Cell::new(0);
    let shared = &count;
    count.set(1);
    shared.set(shared.get() + 1);
    assert_eq!(count.get(), 2);
}
```

| 要做什么 | 方法 |
| --- | --- |
| 读一份副本（`T: Copy`） | `get()` |
| 替换整个值（不要求 `T: Copy`） | `set(new)`；需要旧值就用 `replace(new)` |
| 独占容器后借用内容 | `get_mut(&mut self)` |
| 消费容器，拿回内容 | `into_inner(self)` |

例如，可以用 `Cell<String>::replace` 换掉字符串并取得旧值，即使 `String` 不能 `Copy`。如果需要通过共享引用直接借用内容的一部分，选用下一节的 `RefCell`。
