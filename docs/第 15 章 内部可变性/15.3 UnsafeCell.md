# 15.3 UnsafeCell

[`UnsafeCell<T>`](https://doc.rust-lang.org/std/cell/struct.UnsafeCell.html) 是标准库提供的内部可变性原语。它允许经由共享的 `&UnsafeCell<T>` 修改包裹的内存，但没有取消 `&mut T` 的独占规则，也不能让并发写入变得安全。

预期编译错误：（E0594）普通共享引用不允许直接写入字段。

```rust,compile_fail,no_run
struct Counter(u32);

impl Counter {
    fn set(&self, n: u32) {
        self.0 = n;
    }
}
```

把普通 `&T` 强制转换为裸指针也不会获得写权限；经由它写入是未定义行为。应从 `UnsafeCell::get` 取得裸指针，再按封装承诺使用它：

```rust
use std::cell::UnsafeCell;

struct Counter(UnsafeCell<u32>);

impl Counter {
    fn set(&self, n: u32) {
        // SAFETY: Counter 不是 Sync，也不暴露内部引用或指针。
        unsafe { self.0.get().write(n) };
    }

    fn get(&self) -> u32 {
        // SAFETY: 指针指向已初始化的 u32；没有并发修改。
        unsafe { self.0.get().read() }
    }
}

fn main() {
    let counter = Counter(UnsafeCell::new(0));
    let shared = &counter;
    shared.set(1);
    assert_eq!(counter.get(), 1);
}
```

`UnsafeCell<T>` 对 `T` 不变。否则就能把存有长借用的单元视为可以写入短借用的单元，再从原来的位置读出已经失效的数据。应用代码优先使用 `Cell`、`RefCell` 或有同步保证的类型；这里只为展示底层边界。
