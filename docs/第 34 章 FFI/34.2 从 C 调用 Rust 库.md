# 34.2 从 C 调用 Rust 库

下面让 C 传入一个可修改的 C 字符串，Rust 原地把 ASCII 小写字母转为大写。C 的 `char *` 在 Rust 中对应 `*mut std::ffi::c_char`。`extern "C"` 约定怎样调用，`#[unsafe(no_mangle)]` 保留 C 端要查找的符号名。

保存为 `capitalize.rs`：

```rust
use std::ffi::c_char;

/// 将以 NUL 结尾的字符串原地转换为 ASCII 大写；空指针不做处理。
///
/// # Safety
/// 非空的 `s` 必须指向同一分配内已初始化、可写且以 NUL 结尾的字节。
/// 调用期间，调用方必须给本函数独占访问这些字节的权限。
// SAFETY: 本库保留唯一的导出符号名 rust_capitalize。
#[unsafe(no_mangle)]
pub unsafe extern "C" fn rust_capitalize(s: *mut c_char) {
    if s.is_null() {
        return;
    }

    let mut p = s.cast::<u8>();
    loop {
        // SAFETY: 调用方保证遍历到 NUL 为止的字节都有效且可写。
        let byte = unsafe { &mut *p };
        if *byte == 0 {
            break;
        }
        byte.make_ascii_uppercase();
        // SAFETY: 当前不是终止字节，下一个字节仍在有效范围内。
        p = unsafe { p.add(1) };
    }
}
```

Rust 端用 `unsafe fn` 表明调用有额外前提；Edition 2024 也要求在函数体里显式标出解引用和指针运算等不安全操作，默认会对缺少 `unsafe {}` 的操作发出警告。空指针检查不能验证其他指针是否有效。

保存以下 C 调用方为 `main.c`。用可写的字符数组，而不是直接传入字符串字面量：

```c
#include <stdio.h>

extern void rust_capitalize(char *s);

int main(void) {
    char text[] = "hello world";
    rust_capitalize(text);
    puts(text);
    return 0;
}
```

在 Linux GNU 上，编译 Rust 静态库并链接到 C 程序：

```bash
rustc --edition=2024 --crate-type=staticlib capitalize.rs
cc main.c libcapitalize.a -o capitalize_demo -ldl -lpthread -lm
./capitalize_demo
```

预期输出是 `HELLO WORLD`。若换目标后链接器报告缺少系统库，可用 `rustc --edition=2024 --crate-type=staticlib --print native-static-libs capitalize.rs` 查询该目标的依赖。
