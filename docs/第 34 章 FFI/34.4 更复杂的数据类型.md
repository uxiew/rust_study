# 34.4 更复杂的数据类型

传递结构体时，用 `#[repr(C)]` 让 Rust 按目标平台的 C 布局排列字段。双方的字段顺序和类型仍必须一致；`repr(C)` 不会改变字段自身的布局，也不会检查指针是否有效。

本例把一条日志从 C 传给 Rust。接口使用 `std::ffi` 提供的 `c_int` 和 `c_char`，不需要额外依赖。涉及系统自身的复杂类型时，可以查找 `libc` 等库提供的对应定义。

| 字符串类型 | 用途 |
| --- | --- |
| `&CStr` | 借用以 NUL 结尾的 C 字符串；不保证 UTF-8 |
| `CString` | Rust 持有的 C 字符串；`CString::new` 会拒绝内嵌 NUL，传出指针期间要保持对象存活 |
| `c"文字"` | 从 Rust 1.77 起可直接写静态 C 字符串字面量，类型为 `&'static CStr` |

### Cargo 动态库与 C 调用方

先运行 `cargo new --lib rust_log`，在 `rust_log/Cargo.toml` 加上：

```toml
[lib]
crate-type = ["cdylib"]
```

将下面的代码保存为 `rust_log/src/lib.rs`。`#[repr(C)]` 用在结构体上；`#[unsafe(no_mangle)]` 只用在要被 C 查找的函数上。

```rust
use std::ffi::{CStr, c_char, c_int};

#[repr(C)]
pub struct RustLogMessage {
    pub id: c_int,
    pub msg: *const c_char,
}

/// 打印一条借用自调用方的日志。
///
/// # Safety
/// 非空的 `msg` 必须指向同一分配内有效、以 NUL 结尾的字节，
/// 且在调用期间保持可读且不被修改。字符串含 NUL 在内须小于等于 `isize::MAX` 字节。
// SAFETY: 本库保留唯一的导出符号名 rust_log。
#[unsafe(no_mangle)]
pub unsafe extern "C" fn rust_log(message: RustLogMessage) {
    let text = if message.msg.is_null() {
        c"<无消息>"
    } else {
        // SAFETY: 由调用方保证上述读取范围和有效期。
        unsafe { CStr::from_ptr(message.msg) }
    };
    println!("id={} message={}", message.id, text.to_string_lossy());
}
```

`to_string_lossy` 会替换无效 UTF-8，而不是把任意 C 字符串直接当成 `&str`。这里不获取 C 缓冲区的所有权，也不保存该指针；除了明确允许的空指针外，调用方必须满足安全约定。

在 `rust_log/` 的父目录创建 `main.c`。下面在 Linux 上演示运行时加载：检查 `dlopen` 和 `dlsym` 的结果，确认找到符号后再调用。

```c
#include <dlfcn.h>
#include <stdio.h>

struct RustLogMessage {
    int id;
    const char *msg;
};

int main(void) {
    void *lib = dlopen("./rust_log/target/debug/librust_log.so", RTLD_NOW);
    if (!lib) {
        fprintf(stderr, "%s\n", dlerror());
        return 1;
    }

    dlerror();
    void *symbol = dlsym(lib, "rust_log");
    const char *error = dlerror();
    if (error || !symbol) {
        fprintf(stderr, "%s\n", error ? error : "missing rust_log");
        dlclose(lib);
        return 1;
    }

    /* POSIX dlsym 支持把查到的函数地址转成对应的函数指针。 */
    void (*log_fn)(struct RustLogMessage) = (void (*)(struct RustLogMessage))symbol;
    log_fn((struct RustLogMessage){.id = 1, .msg = "来自 C"});
    log_fn((struct RustLogMessage){.id = 2, .msg = NULL});
    dlclose(lib);
    return 0;
}
```

在同一目录执行（这里使用默认的 Cargo 构建目录）：

```bash
cargo build --manifest-path rust_log/Cargo.toml
cc -Wall -Wextra main.c -o log_demo -ldl
./log_demo
```

库路径相对于程序的运行目录。成功时会打印两条日志，分别包含 `来自 C` 和 `<无消息>`。
