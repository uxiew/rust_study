# 16.5 智能指针

| 类型 | 管理方式 | `clone()` 的主要行为 |
| --- | --- | --- |
| `Box<T>` | 独占持有一个值 | 需要 `T: Clone`，克隆值。 |
| `Rc<T>` | 共享持有，单线程引用计数 | 增加强引用计数，不克隆 `T`。 |
| `Arc<T>` | 共享持有，原子引用计数 | 增加强引用计数，不克隆 `T`。 |
| `Cow<'a, B>` | 在借用和拥有之间切换 | 借用状态复制引用，拥有状态克隆内容。 |

## 引用计数

`Rc<T>` 实现了 `Deref<Target = T>`，所以可以调用内部值的共享方法；它不实现 `DerefMut`。要在共享所有权下修改数据，可以用 `Rc<RefCell<T>>`：

```rust
fn main() {
    use std::{cell::RefCell, rc::Rc};

    let a = Rc::new(RefCell::new(vec![1]));
    let b = Rc::clone(&a);
    b.borrow_mut().push(2);
    assert_eq!(*a.borrow(), [1, 2]);
    assert_eq!(Rc::strong_count(&a), 2);
}
```

最后一个强引用消失时会析构内部值；弱引用不保活该值，但会保留管理分配所需的内存，直到最后一个弱引用也被释放。跨线程需要原子计数时可使用 `Arc`，不过 `Arc<T>` 本身不会让不满足线程安全条件的 `T` 变得安全。

## 写时克隆

`Cow::to_mut` 需要可变内容时才把借用转换为拥有。下面只在需要修改时分配：

```rust
fn main() {
    use std::borrow::Cow;

    fn without_spaces(text: &str) -> Cow<'_, str> {
        let mut result = Cow::Borrowed(text);
        if text.contains(' ') {
            result.to_mut().retain(|c| c != ' ');
        }
        result
    }

    assert!(matches!(without_spaces("rust"), Cow::Borrowed(_)));
    assert_eq!(without_spaces("rust lang"), "rustlang");
}
```
