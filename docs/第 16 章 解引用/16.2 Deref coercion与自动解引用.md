# 16.2 Deref coercion 与自动解引用

## Deref coercion

当形参、带类型标注的绑定等位置要求 `&U` 时，若 `T: Deref<Target = U>`，编译器可以把 `&T` 转换为 `&U`；如果有 `DerefMut`，也可以把 `&mut T` 转成 `&mut U`。转换可以连续执行，但不会把共享引用变成可变引用。

```rust
fn greet(name: &str) {
    println!("Hello, {name}!");
}

fn main() {
    let boxed = Box::new(String::from("Rust"));
    greet(&boxed); // &Box<String> -> &String -> &str
}
```

## 自动解引用

调用 `value.method()` 时，编译器会搜索接收者的候选类型，尝试解引用和自动借用。这与普通函数自动插入 `&` 不同：上一例仍需要显式写 `greet(&boxed)`。

| 场景 | 编译器做什么 |
| --- | --- |
| 形参要求 `&str`，实参为 `&String` | 在强制转换位置得到 `&str`。 |
| 调用 `value.len()` | 搜索接收者的候选类型；例如 `&&&&str` 也可调用 `str::len`。 |
| 用字符串字面量匹配 `&String` | 不为模式做这种强制转换；用 `value.as_str()`。 |

类型转换在编译期确定，但用户实现的 `Deref::deref` 并不一定没有运行成本。适合自动解引用的类型应当表现得像指针，解引用不应意外失败或执行昂贵操作。
