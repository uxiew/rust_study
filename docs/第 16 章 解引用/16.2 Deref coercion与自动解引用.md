# 16.2 Deref coercion 与自动解引用

## Deref coercion

在函数实参、带类型的绑定等强制转换位置，若 `T: Deref<Target = U>`，编译器可以将 `&T` 或 `&mut T` 转为 `&U`；有 `DerefMut` 时也可以把 `&mut T` 转为 `&mut U`。它不是写 `*v` 时自动进行的每一步。下例用 `MyBox<T>` 包裹 `String`：

```rust
use std::ops::Deref;

struct MyBox<T>(T);

impl<T> MyBox<T> {
    fn new(x: T) -> MyBox<T> {
        MyBox(x)
    }
}

impl<T> Deref for MyBox<T> {
    type Target = T;
    fn deref(&self) -> &Self::Target {
      &self.0
    }
}

fn hello(name: &str) {
    println!("Hello, {name}!");
}

fn main() {
    let m = MyBox::new(String::from("Rust"));

    // 这里会自动使用 Deref coercion 将 &m 转换为 &str
    hello(&m); // 输出: Hello, Rust!
}
```

`hello` 需要 `&str`。转换链是 `&MyBox<String> → &String → &str`，因为 `MyBox<T>` 的解引用目标是 `T`，而 `String` 的解引用目标是 `str`。

Deref coercion 是一种特性，它允许自动进行类型转换，将实现了Deref trait 的类型转换为目标类型的引用。
通过解引用转换，我们可以更方便地使用不同类型的智能指针和引用，而无需显式地调用 `deref` 方法或进行类型转换。
`Box<String>` 也可以通过 `&Box<String> → &String → &str` 完成转换。路径在编译期确定，但用户实现的 `deref` 仍可能执行代码。可变引用可以缩小权限为共享引用，反向则不行。

## 自动解引用

Rust 提供的“自动解引用（Automatic Dereferencing）”机制，是在某些场景下“隐式地”、“自动地”帮我们做了一些事情。什么是自动解引用呢？下面用一个示例来说明：

```rust
fn main() {
    let s = "hello";
    println!("length: {}", s.len());
    println!("length: {}", (&s).len());
    println!("length: {}", (&&&&&&&&&&&&&s).len());
}
```

编译，成功。查文档我们可以知道，`len()` 这个方法的签名是：

```text
fn len(&self) -> usize
```

它接受的 receiver 参数是 `&str`，因此我们可以用 UFCS 语法调用：

```rust
fn main() {
    let s = "hello";
    println!("length: {}", str::len(s));
}
```

但是，如果我们使用 `&&&&&&&&&&str` 类型来调用成员方法，也是可以的。原因就是，Rust 编译器帮我们做了隐式的`deref`调用，当它找不到这个成员方法的时候，会自动尝试使用`deref`方法后再找该方法，一直循环下去。

例如 `&&&str` 会在方法查找时一步步解引用到可以匹配 `str::len` 的类型。方法查找还会尝试自动借用；普通函数实参不因此自动加 `&`。

需要注意的是，这里的“自动解引用”更侧重于编译器在语法糖（syntactic sugar）层面上的行为，而 Deref coercion 则更侧重于类型系统层面的自动转换。

| 场景 | 编译器做什么 |
| --- | --- |
| 形参要求 `&str`，实参为 `&String` | 在强制转换位置得到 `&str`。 |
| 调用 `value.len()` | 搜索接收者的候选类型；例如 `&&&&str` 也可调用 `str::len`。 |
| 用字符串字面量匹配 `&String` | 不为模式做这种强制转换；用 `value.as_str()`。 |

类型转换在编译期确定，但用户实现的 `Deref::deref` 并不一定没有运行成本。适合自动解引用的类型应当表现得像指针，解引用不应意外失败或执行昂贵操作。
