# 16.3 自动解引用的用处

智能指针常把内部值当成自己的解引用目标。对 `Rc<String>` 调用 `bytes()` 时，方法查找可以依次到达 `String` 和 `str`；它没有复制字符串，也没有取得字符串的所有权。

```rust
use std::rc::Rc;

fn main() {
    let text = Rc::new(String::from("rust"));
    assert_eq!(text.bytes().next(), Some(b'r'));

    let boxed = Box::new(String::from("rust"));
    let borrowed = &*boxed; // 借用 Box 内部的 String
    assert_eq!(borrowed, "rust");
    assert_eq!(*boxed, "rust"); // 仍可使用
}
```

预期编译错误：（E0382）`let moved = *boxed` 移出了 `Box` 内的非 `Copy` 值，之后不能再使用 `boxed`。

```rust,compile_fail,no_run
fn main() {
    let boxed = Box::new(String::from("rust"));
    let moved = *boxed;
    println!("{boxed} {moved}");
}
```

`Box<T>` 支持从拥有的盒子中移出值，这是特殊能力。一般的 `Deref` 只返回引用，不能据此从自定义智能指针或 `Rc<T>` 移出一个非 `Copy` 值。
