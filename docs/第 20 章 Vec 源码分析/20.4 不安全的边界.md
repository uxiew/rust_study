# 20.4 不安全的边界

安全方法可以在内部调用 `unsafe`，前提是它对**所有合法调用**都能守住不变量。`Vec<T>` 的核心不变量是前 `len` 个槽位均为已初始化且有效的 `T`，并且 `len <= capacity`。

写入空闲容量时可以借用 `MaybeUninit<T>`，不会提前把槽位当作 `T`：

```rust
fn main() {
    let mut values: Vec<u32> = Vec::with_capacity(2);
    let spare = values.spare_capacity_mut();
    spare[0].write(10);
    spare[1].write(20);

    // SAFETY: 容量至少为 2，前 2 个槽位已经写入有效的 u32。
    unsafe { values.set_len(2) };
    assert_eq!(values, [10, 20]);
}
```

`set_len` 不会完成初始化，也不会析构被移出长度范围的元素。一般使用 `push`、`extend` 或 `truncate` 即可。若批量初始化期间会运行可能 panic 的用户代码，还要维护已完成的范围，见第 20.7 节。
