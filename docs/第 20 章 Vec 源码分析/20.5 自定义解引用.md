# 20.5 自定义解引用

`Vec<T>` 实现了 `Deref<Target = [T]>` 和 `DerefMut`，只把已经初始化的元素作为切片暴露出去。这使得 `Vec` 可以调用切片的算法，也可以在函数要求 `&[T]` 的地方自动转换成切片。

```rust
fn main() {
    fn total(numbers: &[u32]) -> u32 {
        numbers.iter().sum()
    }

    let mut numbers = vec![3, 1, 2];
    numbers.sort_unstable();
    assert_eq!(total(&numbers), 6);
    assert_eq!(&numbers[1..], &[2, 3]);
    assert_eq!(numbers.get(3), None);
}
```

只需要查看元素的函数，通常应接收 `&[T]` 而不是 `&Vec<T>`，这样数组、切片和 `Vec` 都能使用。索引表达式越界时 panic；如果越界可能发生，使用返回 `Option` 的 `get`。
