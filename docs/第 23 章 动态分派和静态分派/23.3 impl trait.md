# 23.3 impl Trait

`impl Trait` 的含义取决于位置。参数位的类型由调用方提供；返回位由实现方决定，调用者通过公开的 trait 约束使用它。

| 位置 | 示例 | 稳定状态 |
| --- | --- | --- |
| 函数参数 | `fn print(x: impl Display)` | 稳定；近似匿名泛型参数 |
| 函数返回值 | `fn range() -> impl Iterator<Item = u8>` | 稳定；隐藏具体返回类型 |
| trait 方法返回值 | `fn items(&self) -> impl Iterator<Item = u8>` | 自 1.75 稳定 |
| 类型别名右侧 | `type Items = impl Iterator<Item = u8>` | Nightly：`type_alias_impl_trait` |
| impl 中的关联类型右侧 | `type Items = impl Iterator<Item = u8>` | Nightly：`impl_trait_in_assoc_type` |

```rust
use std::fmt::Display;

fn format_value(value: impl Display) -> String {
    value.to_string()
}

fn even_numbers() -> impl Iterator<Item = u8> + Clone {
    (0..6_u8).filter(|n| n % 2 == 0)
}

fn main() {
    assert_eq!(format_value(7), "7");
    assert_eq!(even_numbers().clone().collect::<Vec<_>>(), [0, 2, 4]);
}
```

两个独立的参数位 `impl Trait` 可以是不同类型；如果要让二者共享同一个类型参数，请用 `fn f<T: Trait>(a: T, b: T)`。返回位若希望调用者使用 `Clone` 等额外接口，应在签名中声明对应约束。

同一函数的返回分支必须产生同一种具体类型。下面预期 E0308：`Range<u8>` 与 `Once<u8>` 即使都实现 `Iterator`，也不是同一类型。若确实需要返回不同类型，可以用枚举包装，或改用 `Box<dyn Iterator<Item = u8>>`。

```rust,compile_fail,no_run
fn values(many: bool) -> impl Iterator<Item = u8> {
    if many { 0..3 } else { std::iter::once(0) }
}
```

::: tip 新版变化
自 Rust 1.75 起，trait 可以在返回位置使用 `impl Trait`，也可以声明 `async fn`。二者都不会让相应的方法自动支持动态分派。Edition 2024 中，普通函数的返回位 `impl Trait` 默认可捕获作用域内的所有泛型参数（包括生命周期）；需要精确指定时可使用 `use<...>`。
:::

```rust
trait Bytes {
    fn bytes(&self) -> impl Iterator<Item = u8> + '_;
}

impl Bytes for String {
    fn bytes(&self) -> impl Iterator<Item = u8> + '_ {
        self.as_str().bytes()
    }
}

fn main() {
    let text = String::from("ab");
    assert_eq!(Bytes::bytes(&text).collect::<Vec<_>>(), [b'a', b'b']);
}
```

如果必须给不透明类型起别名，以下两个位置在稳定版还不可用。这个实验示例需要 Nightly 的 `type_alias_impl_trait` 和 `impl_trait_in_assoc_type`；`#[define_opaque]` 指明由哪个函数确定别名背后的具体类型。

```rust:{channel:"nightly",edition:"2024"}
#![feature(type_alias_impl_trait, impl_trait_in_assoc_type)]

type Values = impl Iterator<Item = u8>;

#[define_opaque(Values)]
fn values() -> Values {
    0..3
}

trait Source {
    type Items: Iterator<Item = u8>;
    fn items(&self) -> Self::Items;
}

impl Source for () {
    type Items = impl Iterator<Item = u8>;
    fn items(&self) -> Self::Items {
        3..5
    }
}

fn main() {
    assert_eq!(values().chain(().items()).collect::<Vec<_>>(), [0, 1, 2, 3, 4]);
}
```

参见 [trait 中的 impl Trait 与 async fn](https://blog.rust-lang.org/2023/12/21/async-fn-rpit-in-traits/)和 [Edition 2024 的返回位生命周期捕获](https://doc.rust-lang.org/edition-guide/rust-2024/rpit-lifetime-capture.html)。
