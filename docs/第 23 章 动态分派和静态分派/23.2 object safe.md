# 23.2 dyn 兼容性

不是每个 trait 都能用来构造 `dyn Trait`。这一条件如今称为 **dyn 兼容性**（旧称 object safety）。

| 接口写法 | 能否在 trait object 上使用 |
| --- | --- |
| `fn name(&self) -> &str` | 可以 |
| `fn make() -> Self where Self: Sized` | 该方法不能通过对象调用，但不妨碍构造对象 |
| `fn print<T>(&self, value: T)` | 不能动态分派；可用 `where Self: Sized` 排除该方法 |
| `fn clone_self(&self) -> Self` | 不能动态分派；调用点不知道该返回哪个具体类型 |
| 普通关联类型，如 `Iterator::Item` | 可以，例如 `&mut dyn Iterator<Item = i32>` |
| 关联常量或泛型关联类型 | 使 trait 不具备 dyn 兼容性 |

如果 trait 本身要求 `Self: Sized`，或者其父 trait 不具备 dyn 兼容性，也不能构造对象。可动态调用的方法不能带类型参数，但可以带生命周期参数；它必须使用可分派的接收者，例如 `&self`、`&mut self` 或 `self: Box<Self>`。直接返回 `impl Trait` 或使用 `async fn` 的方法也不能动态分派。

下面预期 E0038：`duplicate` 返回具体的 `Self`，阻止构造 `&dyn Label`。

```rust,compile_fail,no_run
trait Label {
    fn duplicate(&self) -> Self;
}

fn use_object(_: &dyn Label) {}
```

如果只想在知道具体类型时调用该方法，在方法上单独添加 `where Self: Sized`：

```rust
trait Label {
    fn name(&self) -> &str;
    fn duplicate(&self) -> Self
    where
        Self: Sized;
}

#[derive(Clone)]
struct Text(String);

impl Label for Text {
    fn name(&self) -> &str { &self.0 }
    fn duplicate(&self) -> Self { self.clone() }
}

fn main() {
    let text = Text(String::from("Rust"));
    let view: &dyn Label = &text;
    assert_eq!(view.name(), "Rust");
    assert_eq!(text.duplicate().name(), "Rust");
}
```

完整条件见 [Rust Reference：Dyn compatibility](https://doc.rust-lang.org/reference/items/traits.html#dyn-compatibility)。
