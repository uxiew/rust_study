# 5.7 trait 别名

多个函数如果反复要求相同的 trait 组合，可以给这组约束起一个名字。

## Stable：超 trait 与一揽子实现

```rust
use std::fmt::{Debug, Display};

trait Printable: Debug + Display {}
impl<T: Debug + Display + ?Sized> Printable for T {}

fn show(value: &impl Printable) -> String {
    format!("{value} ({value:?})")
}

fn main() {
    assert_eq!(show(&42), "42 (42)");
}
```

`Printable` 是一个新的 trait；一揽子实现让满足 `Debug + Display` 的类型自动实现它。

## Nightly：真正的 trait 别名

::: tip 新版变化
截至 Rust 1.100.0，[trait_alias](https://doc.rust-lang.org/unstable-book/language-features/trait-alias.html) 仍需 Nightly 和 `#![feature(trait_alias)]`。别名不是新的 trait，不能单独为类型实现它。当前别名右侧支持一个普通 trait 加若干 auto trait。
:::

```rust:{channel:"nightly",edition:"2024"}
#![feature(trait_alias)]

use std::fmt::Debug;

trait ThreadDebug = Debug + Send;
fn describe(value: impl ThreadDebug) -> String {
    format!("{value:?}")
}

fn main() {
    assert_eq!(describe(42), "42");
}
```
