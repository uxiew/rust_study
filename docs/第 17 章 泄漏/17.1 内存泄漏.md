# 17.1 内存泄漏

`Rc::clone` 新建一个拥有同一对象的强引用。只要强引用计数不为零，内部值就不会析构。如果两个节点都通过强引用拥有对方，外部变量消失后，计数仍然各为 1，两个节点都不会释放。

```mermaid
flowchart LR
    A["父节点"] -->|"强引用：拥有子节点"| B["子节点"]
    B -.->|"弱引用：只向上查找"| A
```

有所有权的方向用 `Rc`，回指用 `Weak`。`Weak::upgrade()` 只有在目标仍存活时才返回 `Some(Rc<T>)`；它本身不增加强引用计数。

```rust
use std::{cell::RefCell, rc::{Rc, Weak}};

#[derive(Default)]
struct Node {
    children: RefCell<Vec<Rc<Node>>>,
    parent: RefCell<Weak<Node>>,
}

fn main() {
    let leaf = Rc::new(Node::default());
    {
        let branch = Rc::new(Node::default());
        branch.children.borrow_mut().push(Rc::clone(&leaf));
        *leaf.parent.borrow_mut() = Rc::downgrade(&branch);
        assert!(leaf.parent.borrow().upgrade().is_some());
        assert_eq!(Rc::strong_count(&branch), 1);
    }
    assert!(leaf.parent.borrow().upgrade().is_none());
    assert_eq!(Rc::strong_count(&leaf), 1);
}
```

替换为弱引用取决于业务含义：谁应该保活谁？如果两个节点都不承担所有权，可以让另一个独立容器拥有节点，仅在边上存索引或弱引用。
