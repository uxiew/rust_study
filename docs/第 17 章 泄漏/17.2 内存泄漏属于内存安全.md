# 17.2 内存泄漏与内存安全

内存泄漏是资源没有及时归还，不等同于读取失效内存或重复释放。安全 Rust 可以泄漏内存；长时间运行的程序仍应跟踪分配增长，不能把这项责任交给编译器。

| 看起来都是“内存没了” | 实际发生了什么 |
| --- | --- |
| 强引用环 | 对象仍有效，但引用计数永远不归零。 |
| 使用已释放的地址 | 地址不再有效，继续访问可能是未定义行为。 |
| 分配失败 | 分配器无法满足请求；可能返回错误或导致进程中止。 |

垃圾回收也不能知道哪些可达对象业务上已经不需要。无论使用哪种内存管理方式，都应该明确谁负责保活一个对象，以及何时撤销这项责任。
