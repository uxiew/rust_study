# 19.2 裸指针

`*const T` 和 `*mut T` 不持有值，也不会释放内存。创建、复制或转换裸指针本身可在安全代码中完成，但指针的类型不保证目标非空、对齐、可用或符合别名规则。把 `*const T` 转为 `*mut T` 不会凭空获得写权限。

```rust
fn main() {
    let mut value = 1_u32;
    let ptr = &raw mut value;
    // SAFETY: ptr 指向仍存活、已对齐的 value；期间没有其他访问。
    unsafe { ptr.write(2) };
    assert_eq!(value, 2);
}
```

::: tip 新版变化
稳定版从 Rust 1.82 支持 `&raw const place` 和 `&raw mut place`：直接产生裸指针，不先构造引用。Edition 2024 默认拒绝对 `static mut` 创建引用；选择同步原语，或在确实需要时审计所有裸指针访问。
:::

只检查 `is_null()` 并不足以把任意裸指针转换为引用。非空指针仍可能悬空、未对齐，或没有访问目标分配的权限。比如，把指向单个 `u32` 的指针转换成 `*mut i64` 并执行写入，超出了原对象的大小；不能运行它来预测会改坏哪一个变量。

要偏移裸指针，可查阅[指针方法的安全约束](https://doc.rust-lang.org/std/primitive.pointer.html#method.add)。例如，`add` 要求非零距离的偏移在同一分配内；生成一个未解引用的地址也不等于可以访问它。
