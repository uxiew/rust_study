# 19.6 未定义行为

未定义行为（UB）意味着语言不对这次执行给出保证。它未必崩溃，也不能以 Debug 构建偶然成功作为证明。

| 操作 | 为什么不允许 |
| --- | --- |
| 读取悬空、越界或不满足对齐要求的地址 | 没有有效的内存访问条件；允许不对齐的专用 API 也要求目标可访问。 |
| 从未初始化的存储中读取一个值 | 字节还不能当作该类型的有效值。 |
| 让 `bool` 具有 0 和 1 以外的位模式 | 破坏类型的有效性要求。 |
| 并发执行未同步的冲突读写 | 构成数据竞争。 |
| 通过普通共享引用写入非 `UnsafeCell` 数据 | 破坏共享引用的别名契约。 |

完整说明见 [Rust Reference：未定义行为](https://doc.rust-lang.org/reference/behavior-considered-undefined.html)。安全调用方也可能触及不健全的库或 FFI；责任在破坏安全契约的实现边界。`panic`、内存泄漏和逻辑错误本身不等于 UB。
