# 19.3 内置函数

## 19.3.1 transmute

[`mem::transmute`](https://doc.rust-lang.org/std/mem/fn.transmute.html) 按位转换同样大小的类型。大小相同不是充分条件：结果还必须满足目标类型的有效性，例如只有 0 和 1 是合法的 `bool` 表示。不应把 `transmute` 当作通用类型转换。

| 需求 | 优先使用 |
| --- | --- |
| 浮点数与位模式互转 | `f32::to_bits` / `f32::from_bits` |
| 从字节解码整数 | `from_le_bytes`、`from_be_bytes` |
| 把一个值从字段中移出，同时留下新值 | `mem::replace` 或 `mem::take` |

## 19.3.2 内存读写

`ptr::read` 从地址读取一个有效的 `T`，不清除原地址。对于不实现 `Copy` 的值，必须避免把原位置也当作仍拥有该值，否则可能重复析构。`ptr::write` 向地址写入新值，不析构原位置的内容；写到已初始化位置时须另行处理旧值。

只有确实需要暂时未初始化的存储时，才用 [`MaybeUninit<T>`](https://doc.rust-lang.org/std/mem/union.MaybeUninit.html) 表达这一状态。调用 `assume_init` 之前必须证明已写入有效的 `T`。不要用已弃用的 `mem::uninitialized` 先造一个无效值再填充。

## 19.3.3 综合示例

读取小端字节序的 `u32` 不需要裸指针，也不依赖主机字节序：

```rust
use std::io::{self, Read};

fn read_u32_le(reader: &mut impl Read) -> io::Result<u32> {
    let mut bytes = [0; 4];
    reader.read_exact(&mut bytes)?;
    Ok(u32::from_le_bytes(bytes))
}

fn main() -> io::Result<()> {
    assert_eq!(read_u32_le(&mut &[0x78, 0x56, 0x34, 0x12][..])?, 0x1234_5678);
    assert_eq!(read_u32_le(&mut &[1, 2][..]).unwrap_err().kind(), io::ErrorKind::UnexpectedEof);
    Ok(())
}
```
