# 19.5 协变

## 19.5.1 什么是协变

若 `'long: 'short`，则 `&'long str` 可以用在需要 `&'short str` 的地方。**型变**描述的是：把这种子类型关系放进另一层类型后，关系是否保留。

| 外层类型 | 对参数的型变 | 直觉 |
| --- | --- | --- |
| `&'a T` | 对 `'a` 和 `T` 都协变 | 可缩短引用的有效期；共享引用不能替换普通的 `T`。 |
| `Vec<T>` | 对 `T` 协变 | 拥有整个容器时，可以按较短生命周期的元素类型使用。 |
| `&'a mut T` | 对 `'a` 协变，对 `T` 不变 | 若允许改变槽位类型，就可能写入比原类型允许的更短的引用。 |
| `UnsafeCell<T>` | 对 `T` 不变 | 共享容器也可以写入槽位。 |
| `fn(T)` | 对参数 `T` 逆变 | 能接受一般输入的函数也能接受其子类型。 |

型变不仅作用于直接的生命周期参数，也作用于类型参数。下面示例把 `Vec<&'static str>` 当作含较短引用的 `Vec` 使用：

```rust
fn main() {
    fn add_label<'a>(mut labels: Vec<&'a str>, label: &'a str) -> Vec<&'a str> {
        labels.push(label);
        labels
    }

    let labels: Vec<&'static str> = vec!["rust"];
    let local = String::from("2024");
    assert_eq!(add_label(labels, &local), ["rust", "2024"]);
}
```

预期编译错误：（E0597）传入 `&mut &'static str` 后，槽位内容的生命周期不能被缩短，因此不能把对 `local` 的借用写进去。

```rust,compile_fail,no_run
fn set<'a>(slot: &mut &'a str, value: &'a str) {
    *slot = value;
}

fn main() {
    let mut slot: &'static str = "rust";
    let local = String::from("临时");
    set(&mut slot, &local);
}
```

## 19.5.2 PhantomData

当包装器只存裸指针，字段类型可能无法表达它与外部借用的关系。借助 `PhantomData<&'a T>`，编译器会把它视为含有 `&'a T` 来推导型变及其他类型约束；标记不占存储，也不能单独证明指针有效。

```rust
use std::marker::PhantomData;

struct View<'a, T> {
    ptr: *const T,
    _borrow: PhantomData<&'a T>,
}

fn view<'a, T>(value: &'a T) -> View<'a, T> {
    View { ptr: value, _borrow: PhantomData }
}
```

更多组合见 [Rust Reference 的型变表](https://doc.rust-lang.org/reference/subtyping.html#variance)。
