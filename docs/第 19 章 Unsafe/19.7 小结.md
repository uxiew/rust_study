# 19.7 小结

优先使用有同等行为的安全 API。确实需要 `unsafe` 时，在函数边界写清调用者必须满足的条件，在每个块旁说明这些条件如何成立。某项操作在一台机器上“能运行”，不是安全依据。

先看使用到的 API 的 `# Safety` 文档，再查 [Rust Reference](https://doc.rust-lang.org/reference/behavior-considered-undefined.html) 和 [Rustonomicon](https://doc.rust-lang.org/nomicon/)；不要把标准库的私有布局和实验性规则当成稳定契约。
