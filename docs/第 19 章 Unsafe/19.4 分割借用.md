# 19.4 分割借用

编译器能识别结构体的不同字段，不会一般性地证明切片的多个索引互不重叠。

预期编译错误：（E0499）第一次借用仍活跃，不能再用独立的索引表达式可变借用原数组。

```rust,compile_fail,no_run
fn main() {
    let mut values = [1, 2, 3];
    let first = &mut values[0];
    let last = &mut values[2];
    *first += *last;
}
```

| 需要同时修改 | 安全写法 |
| --- | --- |
| 结构体的不同字段 | 分别借用 `&mut pair.left` 和 `&mut pair.right`。 |
| 切片上的两个连续区间 | `split_at_mut(mid)`，越界时 panic；或用 `split_at_mut_checked`。 |
| 用任意索引选取不相交的元素或区间 | Rust 1.86 起可用 `get_disjoint_mut`，越界或重叠返回错误。 |

```rust
fn main() {
    let mut values = [1, 2, 3];
    let [first, last] = values.get_disjoint_mut([0, 2]).unwrap();
    *first += *last;
    assert_eq!(values, [4, 2, 3]);
    assert!(values.get_disjoint_mut([0, 0]).is_err());
}
```

`split_at_mut` 的内部做法可以用如下简化版理解：先验证切点，再基于同一有效的切片构造两段互不重叠的可变切片。业务代码请直接调用标准库。

```rust
fn main() {
    fn split<T>(values: &mut [T], mid: usize) -> (&mut [T], &mut [T]) {
        let len = values.len();
        assert!(mid <= len);
        let ptr = values.as_mut_ptr();
        // SAFETY: 两段都在原切片内，互不重叠，且借用不超出原切片。
        unsafe {
            (
                std::slice::from_raw_parts_mut(ptr, mid),
                std::slice::from_raw_parts_mut(ptr.add(mid), len - mid),
            )
        }
    }

    let mut values = [1, 2, 3];
    let (left, right) = split(&mut values, 1);
    left[0] += right[0];
    assert_eq!(values, [3, 2, 3]);
}
```
