# 14.1 NLL 希望解决的问题

NLL（Non-Lexical Lifetimes，非词法生命周期）按**控制流和引用用途**判断借用必须在哪里有效，而不是一律延长到花括号末尾。

::: tip 新版变化
从 Rust 1.63 起，[所有 Edition 都使用 NLL](https://blog.rust-lang.org/2022/08/05/nll-by-default/)。旧检查器通常需要额外的作用域才能接受下面这段代码；在稳定版不需要。
:::

```rust
fn main() {
    let mut text = String::from("rust");
    let view = &text;
    println!("{view}"); // 最后一次使用这个共享借用
    text.push('!');     // 可以重新取得可变借用
    assert_eq!(text, "rust!");
}
```

绑定 `view` 的名字仍在作用域内。如果在 `push` 之后再读取它，前一次借用就必须覆盖写入点。

预期编译错误：（E0502）共享借用跨越了可变借用。

```rust,compile_fail,no_run
fn main() {
    let mut text = String::from("rust");
    let view = &text;
    text.push('!');
    println!("{view}");
}
```
